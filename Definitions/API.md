# API

## Definition

An **API (Application Programming Interface)** is a set of rules and tools that allows different software applications to communicate with each other.

## Description

APIs define how requests should be made, how data is formatted, and how responses are returned.  
They can be used to connect applications, services, or devices, enabling them to share data and functionality without needing to understand each other’s internal code.  

Types of APIs include:
- **REST APIs** (most common on the web, using HTTP requests).
- **GraphQL APIs** (flexible queries with a single endpoint).
- **SOAP APIs** (older, XML-based standard).

## Example

- When you log in to a website using your Google account, the website uses Google’s API to authenticate you.  
- Weather apps often call a weather service’s API to fetch forecast data.
